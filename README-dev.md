# Band Practice Mixer - 開発メモ

## 目的
Android / iPhone のブラウザから各自の MP3 / WAV を読み込み、AIでステム分離し、各パートを同期再生しながらスライダーで0〜100%の音量調整を行うバンド練習用Webアプリ。

## 確定要件
- Webアプリ
- Android / iPhone 対応
- MP3 / WAV
- 5分超の曲を想定
- スマホから直接アップロード
- パート別の無段階音量調整
- 将来：曲開始前のカウント
- Amazon Music Unlimited は対象外

## 実装段階
1. 音源選択・ローカル再生（現在）
2. クラウドAI分離API
3. 複数ステムの同期再生・ミキサー
4. 保存・再利用
5. カウントイン

※ 現在のスライダーはUI確認用で、まだAI分離音源の音量には接続していません。
